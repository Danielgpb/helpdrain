# Prompts photos HelpDrain — prêts à copier-coller (autosuffisants)

Une photo hero par page, 34 blocs. Chaque bloc est **complet et indépendant** : style, sujet, lumière, palette et format sont dedans. Tu copies le bloc, tu le colles dans ton générateur, c'est tout.

**Réglages**
- Format : **1920 × 1080 minimum, ratio 16:9** (sauf le bloc 33 « à propos » : carré 1080 × 1080).
- Midjourney : ajoute en fin de prompt ` --ar 16:9 --style raw --no text, logo, watermark, cartoon` (bloc 33 : ` --ar 1:1`).
- Flux / Ideogram / nano-banana : colle le bloc tel quel et choisis 16:9 dans l'interface.
- Génère tout dans la même session (même seed si possible) : la lumière et la palette restent identiques sur tout le site.
- Ensuite envoie-moi les images : je les passe en WebP 1600 px et je les branche dans les pages.

**Palette commune** (déjà écrite dans chaque bloc, juste pour info) : tenue de travail bleu marine, accents orange sécurité (gants, tuyau, bande du camion) pour rester dans la famille HelpCar, pierre grise et brique rouge bruxelloise, lumière naturelle. Visages jamais nets (évite l'effet IA et le problème de droit à l'image). Rien de sale ni de dégoûtant à l'image : on montre le métier, le matériel et le bâti, pas les eaux usées.

Elles s'affichent automatiquement en haut des cartes d'étapes dès qu'elles sont dans `assets/img/` (dépose-les avec n'importe quel nom contenant `etape-1` à `etape-4`, puis `npm run images`).
